# Supabase PostgreSQL Connection String Guide
# ============================================
# This file is an example/template. It is SAFE to commit.
# Never put real credentials in this file.
#
# ── Option A : ASP.NET Core User Secrets (Recommended for local development) ──
#
#   1. Open a terminal in the backend/InventoryManagement.Api folder.
#   2. Run:
#
#      dotnet user-secrets set "ConnectionStrings:DefaultConnection" \
#        "Host=<project-ref>.supabase.co;Port=5432;Database=postgres;Username=postgres;Password=<your-password>;SSL Mode=Require;Trust Server Certificate=true"
#
#   Replace:
#     <project-ref>   → your Supabase project reference (found in Project Settings → Database)
#     <your-password> → your Supabase database password
#
#   Your secret is stored locally at:
#     Windows : %APPDATA%\Microsoft\UserSecrets\ff522dd4-f01b-4fac-b1d7-631886b0ae43\secrets.json
#     Linux/macOS: ~/.microsoft/usersecrets/ff522dd4-f01b-4fac-b1d7-631886b0ae43/secrets.json
#
#   This path is OUTSIDE the repository and is NEVER committed to source control.
#
# ── Option B : Environment Variable (CI/CD, Docker, Production) ───────────────
#
#   Set the environment variable:
#
#     Windows (PowerShell):
#       $env:ConnectionStrings__DefaultConnection = "Host=..."
#
#     Linux/macOS:
#       export ConnectionStrings__DefaultConnection="Host=..."
#
#   Note: ASP.NET Core maps double-underscore (__) to colon (:) in config keys.
#
# ── Where to find your Supabase connection details ────────────────────────────
#
#   1. Go to https://supabase.com/dashboard
#   2. Select your project
#   3. Go to Project Settings → Database
#   4. Under "Connection string" select ".NET / Npgsql"
#   5. Copy the connection string (it looks like the template above)
#
# ── Connection String Parameters Reference ────────────────────────────────────
#
#   Host                   = <project-ref>.supabase.co
#   Port                   = 5432
#   Database               = postgres
#   Username               = postgres (or your custom role)
#   Password               = <your-database-password>
#   SSL Mode               = Require       ← Required by Supabase
#   Trust Server Certificate = true        ← Required for Supabase self-signed certs
#
#   Full example (replace placeholders):
#   Host=abcdefghijklmnop.supabase.co;Port=5432;Database=postgres;Username=postgres;Password=REPLACE_ME;SSL Mode=Require;Trust Server Certificate=true
